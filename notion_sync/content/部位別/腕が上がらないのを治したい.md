# 腕が上がらないのを治したい

## 原因

- 肩甲骨の可動性がない
- 上腕肩甲リズムが適切に起こらない
- 三角筋・僧帽筋の筋力低下、または両者の同時収縮ができていない
- 猫背姿勢により肩関節が内旋し、関節面のアライメントが崩れることで、外転動作が適切に行えない

> 💡 **用語解説: 上腕肩甲リズム**
> 腕を上げる(外転)動作の際、上腕骨と肩甲骨が一定の比率(目安として2:1)で連動して動く仕組み。このリズムが崩れると、腕が上がりにくくなったり、痛みの原因になったりする。

> 💡 **基礎知識: なぜ肩甲骨も一緒に回転する必要があるのか**
> 腕を真上まで上げる動作を、もし上腕骨(肩関節)の動きだけで完結させようとすると、途中で上腕骨の骨頭が肩峰(肩甲骨の突起)にぶつかってしまい、それ以上は上げられなくなる。肩甲骨が上方に回転しながら動くことで、肩峰の位置ごと動かして上腕骨がぶつからないための逃げ道(スペース)を作り出している。三角筋・僧帽筋・前鋸筋などが連動してこの肩甲骨の回転を作り出せないと、腕を無理に上げようとして肩峰の下に組織が挟み込まれ、インピンジメント症候群のような痛みにつながりやすい。

## 情報収集で確認すること

- 痛みが出て腕を上げられないのか
- 腕を上げるとすぐ疲れてしまうのか
- もともと上がらないのか、いつから上がらなくなったのか
- どんな時に困るのか

## フィジカルチェック

- 肩関節外転動作(三角筋・僧帽筋が連動しているか、肩甲骨が上方回旋しているか)
- 腹臥位(うつ伏せ)での肩甲骨の位置、肩甲骨内転筋の動作確認
- 広背筋・前鋸筋の可動性
- 痛みが出る動きと、出ない動きの両方を確認する

## トレーニングの方針

### ①肩甲骨の動きを出す(広背筋の柔軟性UP)

上腕肩甲リズムが適切に出るようにする。

| 課題 | 種目 | L1(初期) | L2(発展) |
| --- | --- | --- | --- |
| 肩甲骨周りの可動性 | 動的ストレッチ | 肩甲骨回し | 前方ロール with ストレッチポール |
| 広背筋トレーニング・静的ストレッチ | - | プルアップ系30回2セット | 静的ストレッチ |
| 前鋸筋トレーニング | - | - | サイドアップ 左右20回2セット |

### ②腕を持ち上げる筋肉のトレーニング(三角筋の筋力UP)

| 課題 | 種目 | L1 | L2 |
| --- | --- | --- | --- |
| 三角筋トレーニング | - | サイドレイズ1kg 20回2セット | サイドレイズ・フロントレイズ1kg 2セット |
| 僧帽筋上部トレーニング | - | シュラッグ1kg 20回2セット(優先順位は低い) | - |

> ⚠️ シュラッグは上腕肩甲リズムを崩す可能性があるため、優先順位は低めに設定する。

### ③肩関節の内旋位を改善(猫背の改善)

| 課題 | 種目 | L1 | L2 |
| --- | --- | --- | --- |
| 上腕骨内外旋の動的ストレッチ | - | 動的ストレッチ | - |
| 大胸筋・小胸筋のトレーニング・静的ストレッチ | - | チェストフライ系30回2セット | 静的ストレッチ |
| 僧帽筋トレーニング | - | ローイング系20回2セット | - |
| 菱形筋トレーニング | - | - | 菱形筋ローイング系20回2セット |
| ローテーターカフのトレーニング | - | - | 側臥位ダンベル1kg 肩甲骨外旋 左右15回3セット |

### ④血行不良の改善(インナーマッスルの動きを出す)

- 上腕骨内外旋の動的ストレッチ
- ローテーターカフ(回旋筋腱板)のトレーニング

### ⑤肩甲骨の安定

広背筋・大胸筋・三角筋・僧帽筋・菱形筋、それぞれのトレーニングをバランスよく行う。
