# 下腹が出る

## アプローチの柱

**筋力を上げる**
- 1週間で1部位あたり20セットを目標にする(宿題を含む)
- 安定した環境できちんと追い込む
- スローカウントで成長ホルモンが分泌されやすい種目を組む
- リカバリー(セット間の休憩)を少なめにする工夫をする

**有酸素運動**
消費カロリーを上げる。

**骨盤後傾へのアプローチ**
過剰な骨盤前傾により内臓が下方に押し出されて下腹が出て見える。多裂筋の拘縮がある場合は、先にコンプレッション(圧迫による調整)を行い、内臓が収まるスペースを作る必要がある。

> 💡 **基礎知識: 骨盤前傾が内臓の位置に影響する仕組み**
> 内臓(特に腸)は腹腔という空間の中に収まっているが、その位置は周囲を囲む筋肉(腹横筋などの腹筋群、骨盤底筋群、横隔膜)の張力バランスによって保たれている。骨盤が過剰に前傾すると、この腹腔を囲む筒状の構造そのものが前方・下方に傾き、内臓を支える底面(骨盤底筋群)の角度も変わってしまうため、内臓が本来の位置よりも前下方に垂れ下がりやすくなる。腹筋群を鍛えて骨盤の傾きを整えることは、単に見た目の引き締めだけでなく、内臓を正しい位置に支え直す土台を作り直す意味合いも持つ。

**腹筋群の強化**
出ようとする内臓を腹筋群で抑える。

## 処方のポイント

- 運動習慣があまりない場合は「全面性の原則」を大切にし、体全体を鍛えつつ目的に合わせて腹筋・下肢の種目をやや多めにするバランスを意識する。トレーニング後に全身疲労感が残る状態を目指す
- 脊柱起立筋は優先順位が低め(もともと筋力がない人は少なく、大きい筋肉でもないため代謝もあまり上がらない)。広背筋・僧帽筋の方が優先順位は高い
- 1時間のセッション内でできる回数と、何を優先するかをよく考える(説明・セット数・時間配分のバランス)
- 初心者でまず筋肉量を増やしたい場合、有酸素運動は3か月後から始めるという進め方も一案

## トレーニングプログラム例

| 課題 | 項目 | L1(初期) | L2(発展) |
| --- | --- | --- | --- |
| 有酸素運動 | - | ランニング5分(アップ)→ランニング15分 | - |
| 筋力UP・骨盤後傾 | 下肢のトレーニング | スクワット系 20回左右4カウント1セット | 片脚スクワット(椅子・脛ポールタッチ)20回左右4カウント1〜3セット |
| | 広背筋 | プルアップ系20回1セット | - |
| | 大胸筋 | プルアップ系20回1セット、プッシュアップ12回 | - |
| 腹部の筋力UP・骨盤後傾 | 腹直筋のトレーニング | Vアップ20回1セット(スモールボールあり) | - |
| | 腹斜筋のトレーニング | ショートV 20回1セット | - |
| 筋肉量UP・拮抗筋 | 脊柱起立筋のトレーニング | バックエクステンション20回2セット(姿勢に応じて変更) | - |

> 💡 食事管理も並行して行う。
