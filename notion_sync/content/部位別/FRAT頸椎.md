# FRAT頸椎(フラット頸椎・ストレートネック)

## 発生のメカニズム

> 💡 **用語解説: 頸椎の前弯とフラット頸椎**
> 本来、頸椎(首の骨)は緩やかに前方へカーブ(前弯)している。うつむいた姿勢(頭を斜め下に傾けた状態)で長時間過ごしていると、この前弯を作る筋群(頭最長筋、頭半棘筋、板状筋など)が使われなくなり、機能低下していく。

- 頸椎がフラットになった状態で正面を向こうとすると、頭を後方に引き上げる後頭下筋群(大後頭直筋、小後頭直筋、下頭斜筋、上頭斜筋)が過剰に収縮する。これがフラット頸椎(いわゆるストレートネック)の人に見られる姿勢
- セルフチェック方法: 仰向けに寝た時、首の下に手が入らない場合は頸椎の前弯が弱くなり、まっすぐになっている可能性がある

## 体への影響

- フラット頸椎になると頭の重心が体より前方に移動する。本来は体の中心に近い位置を頭の重心が通るため、筋力をあまり使わずに支えられるが、重心が前方へ移動すると後方の筋肉(本来カーブを作る筋肉)が余分に働く必要が出てくる
- フラット頸椎の状態では僧帽筋上部が引き伸ばされる。僧帽筋上部は後頭骨に付着しているため、頭が下がりたるむのを防ぐように、代償として肩甲骨をやや挙上させてたるみを作る。この代償動作が肩こりの症状につながる

## 改善のためのアプローチ

- フラット頸椎は、頸椎を前弯させる板状筋や脊柱起立筋の機能低下によって起こるため、頸椎の屈曲・伸展動作を繰り返し行い、これらの筋肉を働かせる
- 伸展動作の際に肩甲骨の内転(寄せる動き)を同時に行うと、より可動域を広げられる
- 首の骨がまっすぐになると、本来背骨が持つ「サスペンション(衝撃吸収)」の機能が失われる。また首は本来、頭の重さを感知するセンサーの役割も担っているが、その感度が鈍くなる
- 猫背などで頭が前に出た姿勢が長時間続くことが主な原因。僧帽筋下部を鍛え、僧帽筋上部・肩甲挙筋をストレッチすることが肩こり改善に役立つ
- 猫背により背中が凝り固まると、首も前に出てストレートネックにつながる。胸の筋肉のストレッチや、脊椎本来のS字カーブを取り戻すアプローチも重要
- 日常生活の中で最も悪影響が大きい姿勢(パソコン作業、スマートフォン、運転、長時間の座位など)を特定し、そこから改善する。同じ姿勢を長時間続けず、30分おきに体を動かすなどの工夫をする

## 原因の整理

頭の重心が本来の位置より前方に移動することで、首・肩の筋肉(脊柱起立筋、僧帽筋、板状筋など)に過剰な伸張ストレスがかかり、肩こりにつながる。また本来あるはずの頸椎前弯が失われることで、頸椎の後方を通る動脈が圧迫され、血流が阻害されることも肩こりの一因になる。

> 💡 **基礎知識: 頭の位置が前に出ると首への負担が急増する理由(てこの原理)**
> 頭部はボウリングの球1個程度の重さ(成人でおよそ5kg前後)があり、この重さを支える負担は、首の付け根から頭の重心までの水平距離(モーメントアーム)に比例して増える。頭が体の真上にある正しい姿勢では首や背中の筋肉にかかる負担は頭の重さとほぼ同程度で済むが、頭が前方に数cm移動するだけで、てこの原理により首・肩の筋肉が支えなければならない実効的な負荷は数倍にまで跳ね上がるとされる。長時間のスマートフォン使用で首・肩がこりやすいのは、この「わずかな前方移動が負担を大きく増幅させる」力学的な仕組みによる。

**主な要因**
- 長時間パソコン・スマートフォンを覗き込む姿勢(頸椎前弯の喪失+後頭下筋群の収縮)
- 長時間、下を向く姿勢
- 猫背などの不良姿勢
- 高すぎる枕
- 腰椎の後弯を頸椎の前弯でバランスを取ろうとしている姿勢
- 柔らかすぎるソファの使用

## 対策・トレーニング

- 血流改善のための動的ストレッチを行う。後頭部は血管・神経が密集しているため、無理のない範囲で動かす
- 頸椎の屈曲・伸展動作と肩甲骨の内転・外転を同時に行うと可動域が広がる
- 頸椎の回旋運動で硬縮した筋群をストレッチする

頸椎が前弯を失いストレートネックになると、バランスを取ろうとして腰椎の後弯・胸椎の過度な後弯・骨盤の後傾が連鎖的に起きやすい。脊椎全体のアライメントを整えるトレーニングが必要。

| 種目 | 分類 | 対象 |
| --- | --- | --- |
| バランスボールエクササイズ | 動的ストレッチ | 体幹 |
| グラビティ前弯トレーニング | トレーニング | 頸椎 |
| 胸椎回旋 | 動的ストレッチ | 胸椎 |
| バックエクステンション | トレーニング | 背部 |
| レッグエクステンション | トレーニング | 大腿四頭筋 |
| ハムストリングス | 静的ストレッチ | 下肢後面 |
| ストレッチポール | セルフケア | 脊柱全体 |

胸椎の過剰な後弯は肩甲骨の外転(開く動き)も同時に引き起こすため、肩甲骨を内転させ自然なポジションへ戻すアプローチも行う。

| 種目 | 分類 |
| --- | --- |
| 大胸筋ストレッチ | 静的ストレッチ |
| 小胸筋ストレッチ | 静的ストレッチ |
| 肩甲骨エクササイズ | 動的ストレッチ |
| 菱形筋トレーニング(ダンベルロウ) | トレーニング |

胸鎖乳突筋(頭部を前下方向に引っ張る筋肉)の静的ストレッチも合わせて行う。
