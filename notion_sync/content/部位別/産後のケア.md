# 産後のケア

## 事前の情報収集(ケース例)

- 動因(何を求めているか)をヒアリングする
- セッション頻度は週1回をベースとする
- 対象: 20代、出産後1か月
- ゴール: 6か月後に産後ケアを終えている状態にしたい、骨盤を締めたい

## 6か月間のトレーニング計画(概念図)

| 種目 | 1ヶ月目 | 2 | 3 | 4 | 5 | 6ヶ月目 |
| --- | --- | --- | --- | --- | --- | --- |
| 腸腰筋 | ● | ● | | | | |
| 大殿筋 | ● | ● | ● | | | |
| インナーユニット | ● | ● | ● | ● | ● | ● |
| 内腹斜筋 | | | | ● | ● | ● |
| 仙腸関節トレーニング | | | | ● | ● | ● |
| 内旋筋群 | | | | ● | ● | ● |
| 外腹斜筋 | | | | | | ● |
| 内転筋群・外転筋群 | | | | | | ● |

> 💡 **用語解説: アウトフレア**
> 出産に伴い骨盤が緩んで外側に開き、恥骨結合も緩んだ状態。

> 💡 **基礎知識: 妊娠中に骨盤が緩む仕組み(リラキシンというホルモン)**
> 妊娠中は「リラキシン」というホルモンの分泌量が大きく増加する。このホルモンは、胎児が産道を通れるよう、骨盤の靭帯や恥骨結合(左右の骨盤をつなぐ軟骨部分)のコラーゲン線維を緩め、骨盤全体の柔軟性を高める働きを持つ。出産後もこのホルモンの影響がしばらく残るため、骨盤まわりの関節・靭帯が通常より緩い(不安定な)状態がしばらく続く。産後1か月はトレーニングを避けるとされるのは、この緩んだ状態のまま負荷の高い運動を行うと、不安定な関節の位置がゆがんだまま固定されてしまうリスクがあるため。

## 優先順位

- **最初にすべきこと**: 腸腰筋のトレーニング(股関節内旋の前提として必要)、大殿筋のストレッチ、インナーユニットの強化
- インナーユニットの強化には6か月かかる(難易度が高いため)
- 大殿筋のストレッチは3か月かけて元の柔軟性に戻す。とにかく最優先で緩める
- 腹斜筋トレーニングは内腹斜筋の時期・外腹斜筋の時期に分けて行う
- 内転筋群・外転筋群は拮抗筋として両方必要だが、内転筋群の方が重要度が高い

## 腸腰筋・インナーユニットの始め方

- 腰椎が過前弯した状態からドローインしながら脚を上げる
- 膝立てから台を使って脚を上げる、ベッドから足を出す、ボールを挟んで負荷を上げる、といった段階を踏む(大きいバランスボールは不向き)
- 股関節が外旋しないよう注意する

## チェック方法: アウトフレア + 腸腰筋の弱さ

スクワットをさせ、立ち上がる際に片脚を上げる動作をしてもらう。この時に膝が外を向く場合は、アウトフレアがまだ戻っていないサイン。

## 避けるべき動き

- 股関節を開くような動き
- 股関節内旋筋群のトレーニングでは、足首を固定し膝の内側に手を当てて抵抗を加える方法を用いる

## 仙腸関節へのアプローチ

> 💡 **用語解説: ペルビックコンディショニング**
> 骨盤周囲の機能を整えるアプローチの総称。おしり歩きや、尾骨・仙骨の下にボール・ハーフカットを置いて固定した状態で脚を屈伸する種目などが含まれる。

アウトフレアの状態のまま動作を習得すると、後から戻しにくくなる。そのため、まずアウトフレアを戻すことを優先する。産後1週間程度から始める場合は、刺激の少ない股関節内旋の種目から入る。

## インナーユニットに関する補足

- 「(お腹が)抜けない状態」を無意識にキープできるようになることが目標
- 出産により骨盤底筋群が緩むと、腹横筋と骨盤底筋群の連動性が落ち、尿漏れの原因になる

## 食事・全体スケジュール

- **産後1か月まで**: トレーニングはNG(諸機能がまだ戻っておらず、骨盤が歪んだ状態のまま固定されるリスクがあるため)。栄養はしっかり摂らせる
- **産後6か月までは痩せやすい時期**とされる(妊娠中についた流動性脂肪が、体が元の体型に戻ろうとする過程で落ちやすいため)
- **1か月〜**: 緩んだ筋肉を引き締める簡単な筋力トレーニング・ストレッチから開始。食事制限はしない。動的ストレッチ、自重エクササイズ(スクワットなど)、静的ストレッチ
- **3か月〜**: ウォーキング・水泳を開始。1日あたり200kcal程度のマイナスを目安に、軽めの筋トレも追加
- **5か月〜**: 筋トレを本格的に強化
