# 反り腰改善

## フィジカルチェック

> 💡 **用語解説: ASIS**
> 上前腸骨棘(Anterior Superior Iliac Spine)。骨盤の前面にある突起で、骨盤の傾き(前傾・後傾)を判断する際の目印になる。

- ASISの位置が恥骨より前に出ているか
- 立位でのフロントライン・バックラインのバランス
- 腸腰筋の柔軟性
- 大腿四頭筋の柔軟性
- 腰背部の柔軟性(座位で骨盤を後傾させられるか)
- 腰椎の可動性
- 広背筋の筋力(ハンズアップスクワットで確認)

## 処方の方針

**①広背筋・僧帽筋の筋力を鍛える**
反り腰は腰椎単体の問題ではなく、脊椎全体のバランスの崩れによって起きると考えられる。脊椎の安定に大きく関与するのが広背筋・僧帽筋。筋力がない人は血液循環も少なく拘縮しているケースが多い(いわゆる白い筋肉のイメージ)。そのためまず低負荷(30〜40RM)から始めて血流を促し、その後15RM程度・週20セット目安のトレーニングに近づけていくと、筋肉の張りが強まり脊椎が安定しやすくなる。先に背骨のアライメントを整えることを優先する。

**②腸腰筋の拘縮を取り、大殿筋の筋力をつける**
運動していない人は腸腰筋が拘縮しやすく、その硬さはストレッチだけでは解消しないことが多い。トレーニングを通じてきちんと腸腰筋を使い、ストレッチも宿題として組み合わせる。同時に大殿筋のトレーニングで骨盤の後傾を作っていく。

**③ハムストリングス・大腿四頭筋のバランス調整**
ハムストリングスが弱ければトレーニングを、大腿四頭筋が強ければストレッチとトレーニングの両方を行う。

**④腰椎の可動性を出す**

**⑤体幹トレーニング**(ドローインや腹直筋のトレーニング)

**⑥生活動作の改善**(ハイヒールの使用など)

**⑦過体重の場合はダイエットも並行する**

## トレーニングプログラム例

| 課題 | 項目 | L1 |
| --- | --- | --- |
| 骨盤後傾の改善 | 腰椎の可動性改善 | ボール潰し、バランスボールトレーニング、キャットバック、ローイング系(負荷10) |
| | 大殿筋のトレーニング | 四つん這い踵アップ 片足左右20回2セット、スプリットスクワット(支えあり)片足20回左右2セット |

| | 静的ストレッチ | ハムストリングス、脊柱起立筋、腸腰筋 |
| | 僧帽筋 | 中部・上部・下部 |
| | 広背筋 | - |
| | 腸腰筋・大腿四頭筋トレーニング | - |
