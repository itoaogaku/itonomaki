# 腰痛(メカニズムと処方の総合ガイド)

腰痛は複数の「ストレス(負荷)」の種類に分けて原因を整理すると理解しやすい。

## ストレスの種類と関わる組織

**伸長ストレス①: 固有背筋外側群(最長筋・腸肋筋)**
脊椎の伸展・回旋動作を担う。伸展作用の80%はこの外側群が担っており、伸展動作の際にここへ伸長ストレスがかかる。

**伸長ストレス②: 固有背筋内側群(多裂筋)**
> 💡 **用語解説: 多裂筋と椎体の安定**
> 多裂筋は椎骨1つ1つを安定させる小さなインナーマッスル。生理的な前弯姿勢で最も活動量が増え、後弯姿勢で活動が低下する。

過剰な伸長ストレス → 腰椎後弯 → 多裂筋の機能低下 → 椎体間の安定性低下、というルート。あるいは、過剰な伸長ストレス → 腰椎後弯 → 筋内圧の上昇 → コンパートメント症候群、というルートもある。

> 💡 **基礎知識: 背中の筋肉でも「コンパートメント症候群」的な痛みが起こる**
> コンパートメント症候群は下腿でよく知られる病態だが、同じ原理(筋膜に囲まれた区画の内圧上昇による血流障害)は背部の固有背筋群でも起こりうる。持続的な過緊張状態が続くと、筋肉自体が腫れて周囲の筋膜内の圧力が高まり、血流が悪くなって酸素・栄養が届きにくくなる。この状態が続くと、実際の組織損傷がなくても、血流不足そのものが痛みの信号(虚血性疼痛)を発生させる。長時間同じ姿勢を続けた後の腰の重だるさ・鈍痛は、こうした筋区画内の一時的な循環不良が一因になっていることがある。

**伸長ストレス③: 胸腰筋膜**
浅葉は上部で広背筋・後鋸筋、下部で大殿筋と連携。深葉は多裂筋を取り込み、腹横筋・腹斜筋と連動する。安静時の姿勢制御や運動時の体幹制御を担う。

**圧縮ストレス④: 腰部椎間関節症**
腰椎の伸展 → 椎間関節に負担 → さらに伸展・回旋が加わる → 椎間関節の関節包を損傷、という流れ。腸腰筋の短縮や股関節伸展筋群の筋力低下が骨盤の傾斜を強め、体幹の筋力低下が過剰な伸展を抑えられなくすることも関与する。

**圧縮ストレス⑤: 腰部椎間板**
腰椎屈曲 → 椎間板後部に伸長ストレス → 回旋が加わるとストレスが増大 → 線維輪内の自由神経を刺激して疼痛。さらに進行すると髄核が脱出し椎間板ヘルニアに至る。固有背筋の筋力低下による骨盤後傾・腰椎後弯が、体幹や股関節伸展筋群の筋力低下を招く悪循環がある。

**圧縮ストレス⑥: 坐骨神経・上殿神経**
梨状筋の拘縮が坐骨神経を圧迫して疼痛(梨状筋症候群)。梨状筋の強い収縮・持続的なスパズムが上殿神経を圧迫することもある。臀部から下肢への放散痛が多い。

**前断ストレス⑦: 仙腸関節**
靭帯への前断ストレスが関節に微細なずれを生じさせる。

## 腰痛につながる機能低下の連鎖

**①固有背筋の筋力低下**
胸郭を含む上半身の重量は固有背筋と胸腰筋膜で支えられている。固有背筋の筋力が低下すると、固有背筋・胸腰筋膜が過緊張して柔軟性が低下し疼痛につながる。また「うなずき運動」(仙骨の前傾動作)の欠如を招き、仙腸関節の不安定性を高める。

**②体幹の筋力低下**
腹横筋・内腹斜筋は胸腰筋膜から起始し腹直筋に停止する構造で、コルセットのように腰部の安定性を高めている。コアの筋力が低下すると、代わりに背筋群が過剰に働いて過緊張し、柔軟性が低下して疼痛につながる。また腸骨稜を内側に引く力が弱まり、仙腸関節の不安定性が高まる。

**③腸腰筋・広背筋の短縮**
腸腰筋の短縮 → 骨盤前傾・腰椎前弯 → 胸腰筋膜・固有背筋が短縮位となり伸張性が低下。

**④股関節伸展筋群の筋力低下**
大殿筋の筋力低下により胸腰筋膜を斜め下方へ牽引できなくなり、腰背部が不安定になる。これを補おうと固有背筋・胸腰筋膜が過緊張し疼痛につながる。梨状筋・殿筋・ハムストリングスは共同で股関節の安定性を保っているため、大殿筋・ハムストリングスの筋力低下は梨状筋への負担増加、ひいては梨状筋の拘縮を招く。

**⑤反うなずき運動**
腹横筋・内腹斜筋・固有背筋・股関節伸展筋群による安定機構が破綻すると「反うなずき運動」が起き、仙腸関節への前断ストレスが増して疼痛につながる。

**⑥仙腸関節の安定性低下**
梨状筋の収縮は仙腸関節を安定させる役割を持つため、仙腸関節の不安定性が高まると梨状筋の拘縮を招く。

**⑦マルアライメント**
平背・円背姿勢では骨盤が後傾し股関節が外旋する。これにより外旋六筋の伸張性が低下し、筋拘縮につながる。

**⑧ライン間の不均衡**
フロントライン(体前面)に対してバックライン(体背面)が相対的に強くなっている状態。

## チェックリスト

- 固有背筋の筋力
- 体幹の筋力
- 股関節伸展筋群の筋力
- 仙腸関節の安定性
- アライメント(骨盤の前傾度合い)

## 症状パターンからの原因推定

- **前屈で痛む**: 腰背部の柔軟性低下が疑われる(①・②・③・④が関連)
- **後屈で痛む**: 反り腰・股関節の過前弯が疑われる(②・③・④が関連)
- **長時間、後弯(丸まった姿勢)で座ると痛い/長時間前弯(反った姿勢)で座れない**: コンパートメント症候群・骨盤後弯が疑われる(①・②・腸腰筋の筋力低下・股関節伸展筋群の短縮・腹直筋の短縮が関連)
- **長時間座っていると痺れる(骨盤後弯)/仙腸関節付近に違和感がある**: 神経の伸張・圧迫が疑われる(⑤・⑥・股関節外旋筋の過使用・機能低下・骨盤後傾・うなずき運動の弱さが関連)

## 実例から見るパターン

- 脚の筋肉量が少ない選手が、物を持ち上げる動作を日常的に行うと腰背部で代償し、腰背部痛につながる
- 加齢とともに中殿筋・大腿筋膜張筋への依存が強まり、下肢全体の筋力が落ちていく
- 大殿筋の筋力低下 → 骨盤の不安定性 → 腰背部への負担、という流れに対しては、大殿筋・中殿筋・腸腰筋で股関節をしっかり支え、あわせて他の筋群の柔軟性・筋力バランスも整える
- 過前弯姿勢は、腸腰筋の硬さ・コアの弱さ・固有背筋の強さの組み合わせで起こりやすい

## トレーニングプログラム(段階的に難易度を上げる例)

### ①固有背筋のトレーニング

座位バックエクステンション → 座位バックエクステンション+ウェイト → 座位バックエクステンション+バランスボール → 背臥位バックエクステンション → 背臥位バックエクステンション+バランスドーム → バックエクステンション+バランスボール → バックエクステンション+バランスボール+ウェイト → 座位キャット&ドッグ → ヒップリフト(椅子使用) → ヒップリフト(バランスボール使用) → バックプランク(ストレッチポール使用) → バックプランク(ストレッチポール+ウェイト) → ヒップリフト片足(バランスボール使用) → デッドリフト → ケーブルロー

### ②腹横筋・内腹斜筋のトレーニング

コアトレーニング(基礎) → サイドベント(足押さえ) → サイドプランク(膝接地) → サイドベント(骨盤アップ) → サイドベント(ショートV) → サイドベント(ロングV) → サイドプランク(足接地) → サイドベント+バランスボール → サイドベント+バランスボール+ウェイト → 立位サイドベント+ウェイト

### ③腸腰筋・広背筋

ストレッチ中心のアプローチ

### ④大殿筋・ハムストリングスのトレーニング

四つん這いヒップレイズ(徒手抵抗)→ ヒップリフト両足 → ヒップリフト片足 → 立位股関節伸展 → ヒップリフト片足伸展 → 立位股関節伸展(徒手抵抗) → ヒップリフト片足伸展(徒手抵抗) → ヒップリフト片足伸展(軸足踵)→ 立位股関節伸展(チューブ使用)

ハムストリングス: レッグカール(徒手抵抗)→ レッグカール(チューブ)→ レッグカール(バランスボール)

**股関節伸展筋群の総合トレーニング**: スクワット → ランジ → ワンレッグスクワット → ワンレッグスクワット(地面タッチ)→ ワンレッグスクワット(後ろ足バランスドーム)→ ワンレッグスクワット(もも裏可動域制限)→ ニーリピーター(足タッチあり/なし)→ ワンレッグスクワット(後ろ足椅子/バランスボール)→ フリーウェイト(60kg〜)

### ⑤仙腸関節の可動性向上

座位キャット&ドッグ(チューブ使用)、四つん這いキャット&ドッグ(チューブ使用)、背臥位(ハーフカット使用)、バランスボールバウンス、ヒップウォーク

### ⑥梨状筋のトレーニング

背臥位股関節屈曲内外旋トレーニング、背臥位くるぶしスモールボール、側臥位膝屈曲内外旋トレーニング(徒手抵抗あり/なし)

> 💡 いずれのプログラムも、まず低負荷・基礎的な種目から始め、選手の状態(痛み・可動域・筋力)を確認しながら段階的にレベルを上げていくのが基本方針。
